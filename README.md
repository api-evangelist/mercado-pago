# Mercado Pago

Mercado Pago is the payments and financial-services arm of Mercado Libre,
Latin America's largest e-commerce and fintech platform. This repository
profiles its developer surface — REST APIs, SDKs, CLI, MCP server, plugins,
and webhooks — using the [APIs.json](https://apisjson.org) format together
with OpenAPI, AsyncAPI, JSON Schema, JSON Structure, JSON-LD, Spectral, and
Naftiko capability artifacts.

## APIs profiled

| API | Description |
|---|---|
| Payments | Core /v1/payments — cards, PIX, boleto, OXXO, SPEI, PSE, account money. |
| Checkout Pro | Hosted preference-based checkout. |
| Checkout Bricks | Composable embedded web components. |
| Checkout API | Server-side card / PIX / boleto flow. |
| Orders API | Unified next-generation orders + transactions resource. |
| Subscriptions | Preapproval recurring subscriptions and plans. |
| Payment Links | No-code shareable URL collection. |
| Customers & Cards | Stored buyers and tokenised cards. |
| Merchant Orders | Aggregate preference + payment(s). |
| Point (POS) | In-person card-reader integration. |
| QR | In-person QR-code collection. |
| Chargebacks | Dispute lifecycle read. |
| Claims | Buyer claim mediation and evidence. |
| Reports | Release and settlement reports. |
| OAuth | Marketplace / platform delegated access. |
| Webhooks | Signed event notifications. |
